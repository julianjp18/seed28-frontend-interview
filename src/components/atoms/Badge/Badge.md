# Badge

Etiqueta pequeña para categorías (ej. "Propio", "Para vaquillona", "Catálogo"). Se usa en las tarjetas de toros.

## Variantes

| Variante  | Uso típico              | Estilo              |
|-----------|-------------------------|---------------------|
| default   | Origen propio           | Fondo primario      |
| success   | Para vaquillona / verde | Fondo verde         |
| secondary | Catálogo / neutro      | Fondo muted         |
| outline   | Borde solo              | Borde, sin relleno  |

## Props

| Prop     | Tipo   | Default   | Descripción  |
|----------|--------|-----------|---------------|
| variant  | string | "default" | Ver tabla     |
| className| string | —         | Clases Tailwind |

Estilos con Tailwind CSS.
