# Divider

Línea de separación entre secciones (sidebar, bloques).

## Props

| Prop        | Tipo   | Default     | Descripción        |
|-------------|--------|-------------|--------------------|
| orientation | string | "horizontal"| horizontal \| vertical |
| className   | string | —           | Clases Tailwind    |

Estilos con Tailwind (`border-border`, `border-t` / `border-l`).
