# Icon

Átomo que renderiza íconos SVG usados en Bulltrack Pro (búsqueda, favorito, dropdown, etc.).

## Nombres disponibles

| Nombre        | Uso                          |
|---------------|------------------------------|
| checkmark     | Checkbox, confirmación       |
| search        | Búsqueda                     |
| download      | Exportar                     |
| list         | Vista lista                  |
| grid         | Vista cuadrícula            |
| info         | Criterios / información     |
| eye          | Ver detalles                |
| heart        | Favorito (outline)          |
| heartFilled  | Favorito (lleno)            |
| location     | Ubicación / establecimiento |
| chevronDown  | Dropdown                     |
| chevronUp    | Acordeón cerrado             |
| arrowLeft    | Volver / Editar criterios   |
| user         | Avatar / usuario            |
| logoB        | Marca Bulltrack              |

## Props

| Prop        | Tipo   | Descripción                    |
|-------------|--------|--------------------------------|
| name        | IconName | Nombre del ícono             |
| className   | string | Clases Tailwind (tamaño, color) |
| aria-label  | string | Accesibilidad (recomendado en botones) |

Estilos con Tailwind. Para tamaño usar por ejemplo `className="size-6"`.
