# BullCardInfo

Molécula: imagen del toro + nombre + subtítulo (raza y edad). Parte de la tarjeta de toro.

## Átomos que usa

- AppImage
- Text (label, caption)

## Props

| Prop     | Tipo   | Descripción        |
|----------|--------|--------------------|
| imageSrc | string | URL de la imagen   |
| imageAlt | string | Alt de la imagen  |
| name     | string | Ej. "Toro #992"   |
| subtitle | string | Ej. "Angus . 36 meses" |
| className| string | Clases Tailwind   |
