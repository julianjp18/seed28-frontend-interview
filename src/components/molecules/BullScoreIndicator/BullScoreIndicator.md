# BullScoreIndicator

Molécula: etiqueta "BULL SCORE" + barra de progreso + texto descriptivo opcional.

## Átomos que usa

- Text (label, caption)
- ProgressBar

## Props

| Prop       | Tipo   | Default | Descripción              |
|------------|--------|---------|--------------------------|
| value      | number | —       | Valor del score (0–max)  |
| max        | number | 1       | Máximo                   |
| description| string | —       | Ej. "Top 1% de..."      |
| className  | string | —       | Clases Tailwind          |
