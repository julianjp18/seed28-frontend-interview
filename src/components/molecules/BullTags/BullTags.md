# BullTags

Molécula: conjunto de badges (Propio, Para vaquillona, Catálogo, etc.) en la tarjeta del toro.

## Átomos que usa

- Badge

## Props

| Prop     | Tipo              | Descripción                    |
|----------|-------------------|--------------------------------|
| tags     | BullTagItem[]     | Array de { label, variant? }   |
| className| string            | Clases Tailwind                |

BullTagItem: `{ label: string, variant?: "default" | "success" | "secondary" | "outline" }`.
