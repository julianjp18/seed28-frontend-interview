# RankingCriteriaLabel

- Icon (info, chevronDown/chevronUp)
- Text

## Props

| Prop      | Tipo     | Default | Descripción    |
|-----------|----------|---------|----------------|
| expanded  | boolean  | false   | Acordeón abierto |
| onToggle  | () => void | —     | Al hacer clic  |
| className | string   | —       | Clases Tailwind |
