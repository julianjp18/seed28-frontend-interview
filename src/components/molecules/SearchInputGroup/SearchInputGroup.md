# SearchInputGroup

Molécula: input de búsqueda con ícono lupa y opcional texto a la derecha (contador de resultados).

## Átomos que usa

- Input (iconLeft search)
- Text (para rightLabel)

## Props

| Prop        | Tipo   | Default                          | Descripción        |
|-------------|--------|----------------------------------|--------------------|
| placeholder | string | "Busca por caravana, nombre o cabaña" | Placeholder   |
| rightLabel  | string | —                                | Ej. "24 resultados" |
| value / onChange | —  | Controlado                       | Igual que input    |
| className   | string | —                                | Clases Tailwind    |
