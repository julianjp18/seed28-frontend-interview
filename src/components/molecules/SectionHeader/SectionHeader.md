# SectionHeader

Molécula: título de sección + descripción opcional + ícono info opcional. Encabezado del área de resultados.

## Átomos que usa

- Text (heading1, body)
- Icon (info)

## Props

| Prop         | Tipo     | Default | Descripción      |
|--------------|----------|---------|------------------|
| title        | string   | —       | Título principal |
| description  | ReactNode| —       | Párrafo debajo   |
| showInfoIcon | boolean  | false   | Mostrar ícono info |
| onInfoClick  | () => void | —     | Al hacer clic en info |
| className    | string   | —       | Clases Tailwind  |
