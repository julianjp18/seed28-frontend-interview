# CurrentObjectiveSection

Organism: current objective text + "Edit criteria" button. Uses ObjectiveDescription and ButtonWithIcon.

## Molecules used

- ObjectiveDescription
- ButtonWithIcon

## Props

| Prop | Type | Description |
|------|------|-------------|
| description | string | Objective paragraph text |
| onEditClick | () => void | When edit button is clicked |
| editButtonLabel | string | Button text (default "Edit criteria") |
| className | string | Tailwind classes |
